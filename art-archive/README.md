# Art archive

`gemini/` holds the Gemini-generated watercolor illustrations that shipped briefly in November 2026
(scene backgrounds, the valley map, Lucky, the reindeer and several objects, plus an unused rabbit).
They were set aside so the whole game uses one drawn style; nothing here is bundled or served.
Provenance is recorded in `public/assets/PROVENANCE.md`. To use one again, copy it back to
`public/assets/` and wire its ID in `src/components/Art.tsx`.

Thư mục `gemini/` giữ các tranh màu nước do Gemini tạo, đã được cất sang đây để cả game dùng một
phong cách vẽ; không tệp nào ở đây được đóng gói hay phục vụ.
